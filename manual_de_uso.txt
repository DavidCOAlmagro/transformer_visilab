MANUAL DE USO
Clasificador de diatomeas (YOLO + DINOv2 con fine-tuning + ResNet50)

Todo se hace con tareas.py (Windows y Ubuntu) o con make (Ubuntu).
Ver la lista completa: python tareas.py --help


0. ANTES DE EMPEZAR
====================
- Instalación: ver readme.md.
- Pesos (no están en git):
    modelos/75_objetivo_ft/modelo_75_objetivo_ft.pth
    Inferir/yolo_dinov2/yolo_best.pt
    Inferir/yolo_dinov2/resnet50_checkpoint_epoch50.pth
- Comprobar:   python tareas.py estado        (Ubuntu: make estado)


1. CLASIFICAR IMÁGENES NUEVAS (INFERENCIA)
===========================================
Pon las imágenes (con subcarpetas) en Inferir/imagenes_inferencia/ o indica otra carpeta:

    python tareas.py inferir                       (Ubuntu: make inferir)
    python tareas.py inferir OTRA_CARPETA --salida CARPETA_RESULTADOS --classifier dinov2

Salida (por defecto ../resultados_<fecha>/):
  classification_results.xlsx (+ uno por modelo): top-1/2/3, confianza, revisión (< 80 %)
  bbox/   imágenes anotadas: recuadro verde y nombre de la especie
  crops/  recortes de cada diatomea


2. MEDIR EN CAMPO
==================
Con el Excel de la inferencia y las etiquetas (cruce_ground_truth.xlsx, hoja Por_imagen):

    python tareas.py evaluar --resultados CARPETA_RESULTADOS --etiquetas cruce_ground_truth.xlsx
    (Ubuntu: make evaluar RESULTADOS=... ETIQUETAS=...)

Mide solo recursos/campo_test.txt (test fijo). Fila importante: suma_conf con excluye_fp = True.
Referencias: DINO-ft 0.830 · ResNet 0.815 · ensamble 0.857.
Si el Excel no tiene ResNet, añade --resnet EXCEL_DE_RESNET.


3. ENTRENAR
============
    python tareas.py dividir-datos      reparto train/val/test → recursos/splits_<prueba>.txt.gz
    python tareas.py entrenar           (Ubuntu: make entrenar, sin freno térmico y con log)

Opciones útiles de entrenar: --epocas, --batch, --bloques, --splits, --salida, --pesos-mlp,
--max-imagenes (prueba rápida), --temperatura-pausa 0 (sin freno térmico).
Si se corta, relanza el mismo comando: continúa desde la última época.
IMPORTANTE: nunca entrenar con imágenes de recursos/campo_test.txt.


4. OTROS
=========
    python tareas.py dividir-campo --etiquetas cruce_ground_truth.xlsx   rehacer test/pool de campo
    python src/auditoria_dataset.py "data/imagenes_visilab(raw)"        distribución y duplicados
    python tareas.py test                                                tests
    python tareas.py limpiar          lista lo regenerable u obsoleto (no borra)
    python tareas.py limpiar --si     lo borra
